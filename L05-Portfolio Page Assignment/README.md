# Lecture-05 — Portfolio

Personal portfolio for MD Shahriar Fardin Protya, IoT engineering student at Savonia UAS.

## Features

- **Skills section** — 8 skill cards (HTML, CSS, JS, Python, IoT, LTspice, Git, Linux)
- **Projects section** — 3 projects with descriptions and GitHub links
- **Theme toggle** — Light/Dark mode switcher using `classList` and a `isDark` state variable
- **localStorage** — Theme preference is saved under key `portfolio_theme` and restored on load
- **Last updated** — Auto-generated date via JavaScript, shown in the footer
